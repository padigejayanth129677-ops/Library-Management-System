# Library Management System

A simple web-based Library Management System developed to demonstrate
Git version control, GitHub collaboration, secure pull requests and CI/CD.

## Features

- Library homepage
- Book management
- Member management
- Book availability
- Git and GitHub version control
- Secure Pull Request workflow
- CI/CD automation

## Technologies

- HTML5
- CSS3
- JavaScript
- Git
- GitHub
- GitHub Actions

## Project Objective

The objective of this project is to demonstrate a secure and controlled
software development workflow using open source technologies.
